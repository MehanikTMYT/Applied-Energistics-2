# Что такое Applied Energistics 2?

# Как пользоваться этим руководством

* Оглавление находится на боковой панели слева
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Плюс](assets/diagrams/plus.png)
и ![Минус](assets/diagrams/minus.png) (масштабирование), камеру можно вращать и перемещать.
Перетаскивайте мышь с зажатой левой кнопкой для вращения, с зажатой правой — для перемещения.

# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механики для логистики и хранения. Огромную
комнату с сундуками можно заменить компактной МЭ-сетью, но это лишь начало.
Applied Energistics предназначен для совместной работы с другими модами сборки и их автоматизации. Можно настроить систему так,
чтобы одним щелчком создавать все промежуточные компоненты (и конечный результат) сложной цепочки рецептов, поддерживать определённое
количество предметов в запасе, создавая новые по мере необходимости, или просто перемещать предметы по базе.
