# Карта памяти

<ItemImage id="memory_card" scale="4" />

Карта памяти используется для копирования и вставки настроек между [устройствами](../ae2-mechanics/devices.md) AE2, а также для связывания
[P2P-тоннелей](p2p_tunnels.md). Она также может устанавливать в устройства [карты улучшений](upgrade_cards.md).

- Щёлкните правой кнопкой мыши с зажатой Shift, чтобы скопировать настройки или создать новую частоту связи P2P.
- Щёлкните правой кнопкой мыши, чтобы вставить настройки, карты улучшений или частоту связи.
