# МЭ шина хранения

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/storage_bus.snbt" />
</GameScene>

Хотелось *сохранить* свой хаотичный склад сундуков, вместо того чтобы заменить его чем-то разумным? Представляем шину хранения!

Шина хранения превращает инвентарь, к которому она прилегает, в [сетевое хранилище](../ae2-mechanics/import-export-storage.md).
Она позволяет сети видеть содержимое этого инвентаря, а также помещает в него и извлекает из него предметы
для нужд [устройств](../ae2-mechanics/devices.md), работающих с сетевым хранилищем.

В AE2 новые механики возникают из взаимодействия функций [устройств](../ae2-mechanics/devices.md), поэтому шину хранения
*необязательно* использовать именно для *хранения*. С помощью [подсетей](../ae2-mechanics/subnetworks.md)
можно сделать одну или несколько шин хранения *единственным* хранилищем сети и использовать их как источник или приёмник
при передаче предметов. Примеры см. в разделе [«Трубопроводная подсеть»](../example-setups/pipe-subnet.md).

ВАЖНО: большие оптимизированные инвентари, например ящики, работают нормально, но большие *неоптимизированные* инвентари с множеством слотов, например
колоссальные сундуки, при подключении через шины хранения сильно ухудшают производительность.

## Фильтрация

По умолчанию шина хранит всё. Предметы, помещённые в слоты фильтра, задают белый список:
храниться смогут только указанные предметы.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если этих предметов нет в наличии.

Нажмите правой кнопкой мыши с ёмкостью для жидкости (например, ведром или баком), чтобы задать фильтр на жидкость, а не на сам предмет ведра или бака.

## Приоритет

Приоритет задаётся нажатием на гаечный ключ в правом верхнем углу интерфейса.
Предметы, поступающие в сеть, в первую очередь направляются в хранилище с наивысшим
приоритетом. Если у двух хранилищ одинаковый приоритет
и одно уже содержит такой предмет, предпочтение отдаётся ему,
а не другому. Хранилища с фильтром считаются уже содержащими соответствующий предмет,
когда сравниваются с другими хранилищами той же группы приоритета. Предметы извлекаются
из хранилища с самым низким приоритетом. Таким образом, по мере добавления и извлечения предметов
в сетевом хранилище хранилища с высоким приоритетом заполняются, а с низким — освобождаются.

## Настройки

*   Фильтр шины можно настроить по текущему содержимому соседнего инвентаря
*   Можно разрешить или запретить сети видеть предметы в соседнем инвентаре, которые шина не может извлечь.
    Например, шина хранения не может извлекать предметы из среднего входного слота <ItemLink id="inscriber" />.
*   Шина может фильтровать и при вставке, и при извлечении либо только при вставке
*   Шина может работать в обоих направлениях, только на вставку или только на извлечение

## Улучшения

МЭ шина хранения поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="capacity_card" /> увеличивает количество слотов фильтра
*   <ItemLink id="fuzzy_card" /> позволяет фильтровать по степени повреждения и/или игнорировать NBT предметов
*   <ItemLink id="inverter_card" /> переключает фильтр с белого списка на чёрный
*   <ItemLink id="void_card" /> уничтожает поступающие предметы, если подключённый инвентарь заполнен. Помогает избежать переполнения ферм. Обязательно настройте фильтр шины хранения!
