# Пространственный пилон

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

Пространственный пилон используется при [пространственном вводе/выводе](../ae2-mechanics/spatial-io.md) для создания пространственного поля и определения объёма,
на который оно действует.

Каждая непрерывная линия пилонов использует 1 [канал](../ae2-mechanics/channels.md)

Для работы линия пилонов должна иметь длину не менее 2 блоков.
