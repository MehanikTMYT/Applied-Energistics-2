# Крохотный динамит

<BlockImage id="tiny_tnt" scale="8" />

Маленький динамит для небольших взрывов. Полезен для создания пар <ItemLink id="quantum_entangled_singularity" />.

В конфигурации можно отключить разрушение блоков его взрывом, чтобы создавать сингулярности без возможности
гриферства, если на сервере требуется запретить обычный динамит и криперов.
