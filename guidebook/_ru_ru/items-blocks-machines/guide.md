# Руководство

<ItemImage id="guide" scale="8" />

### Руководство, которое сейчас открыто, — источник всей необходимой информации об AE2.

* Оглавление находится на боковой панели слева
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Плюс](../assets/diagrams/plus.png)
  и ![Минус](../assets/diagrams/minus.png) (масштаб), камеру можно вращать и перемещать.
  Для вращения перетаскивайте мышь с зажатой левой кнопкой, для перемещения — с правой.
