# Высекатель

<BlockImage id="inscriber" scale="8" />

Высекатель используется для изготовления схем и [процессоров](processors.md) с помощью [прессов](presses.md), а также для измельчения различных предметов в пыль.
Он принимает как энергию AE2 (AE), так и Fabric/Forge Energy (E/FE). Можно включить распределение по сторонам, при котором предметы, подаваемые с разных сторон,
попадают в разные слоты его инвентаря. Для удобства высекатель можно поворачивать с помощью <ItemLink id="certus_quartz_wrench" />.
Его также можно настроить на выталкивание результатов изготовления в соседние инвентари.

Размер входного буфера регулируется. Например, если из одного инвентаря подаются материалы в большой массив высекателей,
лучше выбрать малый буфер, чтобы материалы распределялись между высекателями равномернее (вместо того чтобы первый
высекатель заполнялся до 64, а остальные оставались пустыми).

Для изготовления [процессоров](processors.md) используются 4 пресса для схем

  <ItemImage id="logic_processor_press" scale="4" />

А пресс для именования позволяет переименовывать блоки подобно наковальне, что удобно для обозначения устройств в <ItemLink id="pattern_access_terminal" />.

## Настройки

* Высекатель может распределять предметы по сторонам (как описано ниже) или принимать их в любой слот с любой стороны, используя внутренний фильтр для определения
    нужного слота. В режиме без распределения по сторонам предметы нельзя извлекать из верхнего и нижнего слотов.
* Высекатель можно настроить на выталкивание предметов в соседние инвентари.
* Размер входного буфера регулируется: большой подходит для отдельного высекателя с ручной подачей,
малый удобен для больших схем с параллельной работой.

## Интерфейс и распределение по сторонам

В режиме распределения по сторонам высекатель определяет назначение предметов по стороне, с которой они поступают или извлекаются.

![Интерфейс высекателя](../assets/diagrams/inscriber_gui.png) ![Стороны высекателя](../assets/diagrams/inscriber_sides.png)

A. **Верхний вход** доступен с верхней стороны высекателя (предметы можно как подавать в этот слот, так и извлекать из него)

B. **Центральный вход** принимает предметы слева, справа, спереди и сзади высекателя (предметы можно только подавать в этот слот, но не извлекать из него)

C. **Нижний вход** доступен с нижней стороны высекателя (предметы можно как подавать в этот слот, так и извлекать из него)

D. **Выход** доступен для извлечения слева, справа, спереди и сзади высекателя (предметы можно только извлекать из этого слота, но не подавать в него)
