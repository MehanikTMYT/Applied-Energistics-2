# МЭ накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

Накопитель — [устройство](../ae2-mechanics/devices.md), в которое устанавливаются [ячейки хранения](storage_cells.md) для использования
в качестве [сетевого хранилища](../ae2-mechanics/import-export-storage.md). В нём 10 слотов, каждый вмещает одну ячейку.

Ячейки можно подавать в его инвентарь и извлекать любыми системами перемещения предметов, например воронками или шинами AE2.

Его можно поворачивать с помощью <ItemLink id="certus_quartz_wrench" />.

## Индикаторы состояния ячеек

У ячеек в накопителе есть светодиодные индикаторы состояния:

| Цвет  | Состояние                                                                           |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пусто                                                                            |
| Синий   | Есть содержимое                                                                |
| Оранжевый | Лимит [типов](../ae2-mechanics/bytes-and-types.md) достигнут, новые типы добавить нельзя     |
| Красный    | Все [байты](../ae2-mechanics/bytes-and-types.md) заняты, новые предметы добавить нельзя |
| Чёрный  | Нет питания или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритет задаётся нажатием на гаечный ключ в правом верхнем углу интерфейса.
Поступающие в сеть предметы в первую очередь направляются в хранилище с наивысшим приоритетом.
Если у двух хранилищ или ячеек одинаковый приоритет,
предпочтение отдаётся тому, где уже есть предметы этого типа,
а не другому. Любые [размеченные](cell_workbench.md) ячейки считаются уже содержащими предмет,
если находятся в одной группе приоритета с другими хранилищами. При извлечении предметов
сначала используется хранилище с наименьшим приоритетом. Таким образом, по мере поступления и извлечения предметов
хранилища с высоким приоритетом заполняются, а с низким — освобождаются.
