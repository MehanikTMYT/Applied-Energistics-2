# МЭ сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ сундук работает как миниатюрная сеть с <ItemLink id="terminal" />, <ItemLink id="drive" /> и <ItemLink id="energy_acceptor" />.
Его можно использовать как небольшую сеть хранения, но вместимость всего в одну [ячейку хранения](../items-blocks-machines/storage_cells.md)
ограничивает пользу такого применения.

Зато он удобен для работы именно с установленной внутри ячейкой хранения. Встроенный терминал видит и открывает доступ только
к предметам в установленной ячейке, тогда как [устройства](../ae2-mechanics/devices.md) общей сети имеют доступ к предметам в любом [сетевом хранилище](../ae2-mechanics/import-export-storage.md),
включая МЭ сундуки.

У него 2 разных интерфейса, а перемещение предметов зависит от стороны. Взаимодействие с верхней панелью открывает встроенный терминал. Через эту сторону можно помещать предметы
в установленную ячейку, но нельзя извлекать их. Взаимодействие с любой другой стороной открывает интерфейс со слотом ячейки хранения
и настройками приоритета. Системы перемещения предметов могут устанавливать и извлекать ячейку только через сторону со слотом ячейки.

Его можно поворачивать с помощью <ItemLink id="certus_quartz_wrench" />.

У него небольшой внутренний запас энергии AE, поэтому без [энергохранилища](../items-blocks-machines/energy_cells.md) в сети
одновременная загрузка или извлечение слишком большого числа предметов может вызвать перебой питания.

Терминал можно окрасить с помощью <ItemLink id="color_applicator" />.

## Настройки

У МЭ сундука те же настройки, что у <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />.
Однако он не поддерживает <ItemLink id="view_cell" />.

## Индикаторы состояния ячеек

У ячеек в сундуке есть светодиодные индикаторы состояния:

| Цвет  | Состояние                                                                           |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пусто                                                                            |
| Синий   | Есть содержимое                                                                |
| Оранжевый | Лимит [типов](../ae2-mechanics/bytes-and-types.md) достигнут, новые типы добавить нельзя     |
| Красный    | Все [байты](../ae2-mechanics/bytes-and-types.md) заняты, новые предметы добавить нельзя |
| Чёрный  | Нет питания или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритет задаётся нажатием на гаечный ключ в правом верхнем углу интерфейса со слотом ячейки.
Поступающие в сеть предметы в первую очередь направляются в хранилище с наивысшим приоритетом.
Если у двух хранилищ или ячеек одинаковый приоритет,
предпочтение отдаётся тому, где уже есть предметы этого типа,
а не другому. Любые [размеченные](cell_workbench.md) ячейки считаются уже содержащими предмет,
если находятся в одной группе приоритета с другими хранилищами. При извлечении предметов
сначала используется хранилище с наименьшим приоритетом. Таким образом, по мере поступления и извлечения предметов
хранилища с высоким приоритетом заполняются, а с низким — освобождаются.
