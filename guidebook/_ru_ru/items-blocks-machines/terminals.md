# Терминалы

В то время как <ItemLink id="pattern_provider" />, <ItemLink id="import_bus" />, <ItemLink id="storage_bus" /> и прочие устройства
служат основными средствами взаимодействия сети AE2 с миром, терминалы обеспечивают взаимодействие сети AE2
с *игроком*. Существуют несколько вариантов с разными функциями.

Терминалы наследуют цвет [кабеля](cables.md), на котором установлены.

Это [части кабеля](../ae2-mechanics/cable-subparts.md).

# Поиск в терминале

Поле поиска терминала поддерживает регулярные выражения (*regex*). Например, запрос "gtceu:.*ore" покажет все руды из GregTech.
Изучение синтаксиса регулярных выражений остаётся самостоятельным упражнением для читателя.

# МЭ терминал

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/blocks/terminal.snbt" />
  <IsometricCamera yaw="180" />
</GameScene>

Базовый терминал позволяет просматривать содержимое [сетевого хранилища](../ae2-mechanics/import-export-storage.md), получать к нему доступ
и запрашивать предметы у системы [автокрафта](../ae2-mechanics/autocrafting.md).

## Интерфейс

Интерфейс базового терминала состоит из нескольких частей

Центральная часть предоставляет доступ к сетевому хранилищу. В него можно помещать предметы и забирать их. Доступны следующие
действия мышью и сочетания клавиш:

*   Левая кнопка мыши берёт стопку. Правая — половину стопки.
*   Если предмет, жидкость или другой ресурс доступен для [автокрафта](../ae2-mechanics/autocrafting.md),
    клавиша действия «Выбрать блок» (обычно средняя кнопка мыши) открывает интерфейс указания количества для изготовления. Можно вводить формулы, например `3*64/2`,
    или указать `=32`, чтобы изготовить только столько предметов, сколько не хватает до 32 в хранилище.
*   Удерживание Shift фиксирует положение отображаемых предметов: они не перестраиваются при изменении количества или поступлении новых предметов.
*   Правая кнопка мыши с ведром или другой ёмкостью помещает жидкость в хранилище.
*   Нажатие левой кнопкой мыши по жидкости пустой рукой забирает ведро этой жидкости, если в сетевом хранилище есть пустое ведро. Нажатие по жидкости с ёмкостью в руке наполняет эту ёмкость.

Слева расположены кнопки настроек:

*   Сортировка по различным признакам: имени, моду, количеству
*   Отображение хранящихся ресурсов, доступных для изготовления или и тех и других
*   Отображение предметов, жидкостей или и того и другого
*   Изменение порядка сортировки
*   Открытие окна подробных настроек терминала
*   Изменение высоты интерфейса терминала

Справа находятся слоты для <ItemLink id="view_cell" />.

Кнопка с молотком в правом верхнем углу центральной части открывает интерфейс состояния [автокрафта](../ae2-mechanics/autocrafting.md),
где видны ход изготовления и задачи каждого [процессора создания](crafting_cpu_multiblock.md).

Есть 2 дополнительные кнопки для перемещения содержимого сетки изготовления в сетевое хранилище или инвентарь игрока.

# МЭ терминал для закодированных шаблонов

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/blocks/pattern_encoding_terminal.snbt" />
  <IsometricCamera yaw="180" />
</GameScene>

МЭ терминал для закодированных шаблонов похож на обычный терминал и имеет те же настройки и разделы, но дополнен
интерфейсом кодирования [шаблонов](patterns.md). Он похож на интерфейс терминала изготовления, однако эта сетка
ничего не изготавливает.

Такой терминал стоит иметь в дополнение к терминалу изготовления.

## Интерфейс

Интерфейс терминала для закодированных шаблонов совпадает с интерфейсом обычного терминала, но дополнен интерфейсом кодирования [шаблонов](patterns.md).

Интерфейс кодирования шаблонов состоит из нескольких частей:

Слот для <ItemLink id="blank_pattern" />.

Большая стрелка для кодирования шаблона.

Слот для закодированных шаблонов. Чтобы изменить существующий шаблон, поместите его в этот слот. Нажмите стрелку кодирования, чтобы перезаписать его новыми данными.

4 вкладки справа выбирают тип шаблона:

*   Изготовление
*   Обработка
*   Кузнечное дело
*   Камнерезка

Центральная часть интерфейса меняется в зависимости от типа кодируемого шаблона:

*   В режиме изготовления:
    *   Добавьте ингредиенты левой кнопкой мыши или перетащите их из JEI/REI, чтобы задать рецепт. Правая кнопка мыши удаляет ингредиент.
    *   Разрешение замен позволяет, например, изготавливать палки из любых досок. Включать его следует
        только при крайней необходимости.
    *   Замена жидкостей позволяет использовать хранящиеся жидкости вместо вёдер с жидкостью.
    *   Также можно закодировать шаблон прямо из окна рецепта JEI/REI.

*   В режиме обработки:
    * Добавляйте ингредиенты левой или правой кнопкой мыши либо перетаскивайте их из JEI/REI, чтобы задать входы и выходы рецепта.
    * Нажмите правой кнопкой мыши с ёмкостью для жидкости (например, ведром или баком), чтобы задать ингредиентом жидкость, а не сам предмет ведра или бака.
    * Если в руке стопка, левая кнопка мыши помещает её целиком, а правая — один предмет. Левая кнопка мыши по уже заданной стопке ингредиента
        удаляет всю стопку, а правая уменьшает её на 1. Клавиша действия «Выбрать блок» (обычно средняя кнопка мыши)
        позволяет задать точное количество предмета или жидкости.
    * Среди выходных слотов есть основной результат и места для побочных продуктов, которые должен учитывать алгоритм автокрафта.
    * Входные и выходные слоты прокручиваются: можно задать 81 различный ингредиент и 26 побочных продуктов.
    * Также можно закодировать шаблон прямо из окна рецепта JEI/REI.

*   Интерфейсы режимов кузнечного дела и камнерезки работают подобно кузнечному столу и камнерезу соответственно.

# МЭ терминал доступа к шаблонам

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/blocks/pattern_access_terminal.snbt" />

Терминал доступа к шаблонам предоставляет доступ ко всем поставщикам шаблонов в сети.
Он решает конкретную проблему: в плотной башне из <ItemLink id="pattern_provider" />
и <ItemLink id="molecular_assembler" /> невозможно физически добраться до поставщиков, чтобы вставить новые шаблоны. Кроме того,
иногда просто не хочется идти через всю базу ради добавления или обновления [шаблона](patterns.md).

## Интерфейс

Интерфейс этого терминала отличается от интерфейсов всех остальных терминалов.

В нём есть настройки высоты терминала и отображаемых поставщиков шаблонов.

Каждая строка терминала соответствует определённому поставщику шаблонов.

Поставщики шаблонов в терминале сортируются и группируются по блокам, к которым подключены,
либо по присвоенным им именам (с помощью <ItemLink id="name_press" /> или наковальни).
