# МЭ шина импорта

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/import_bus.snbt" />
</GameScene>

Шина импорта извлекает предметы и жидкости (а с дополнениями — и другие ресурсы) из прилегающего инвентаря и отправляет их в
[сетевое хранилище](../ae2-mechanics/import-export-storage.md).

Для снижения нагрузки шина импорта, которая давно ничего не импортировала, переходит в своего рода
«спящий режим» и работает медленнее. После успешного импорта она просыпается и разгоняется до полной скорости (4 операции в секунду).

Это [компоненты кабеля](../ae2-mechanics/cable-subparts.md).

## Фильтрация

По умолчанию шина импортирует всё доступное. Предметы в её слотах фильтра задают белый список,
разрешающий импортировать только указанные предметы.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если их нет в наличии.

Щёлкните правой кнопкой мыши с ёмкостью для жидкости (например, ведром или резервуаром), чтобы задать фильтр по жидкости, а не по самому ведру или резервуару.

## Улучшения

Шина импорта поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="capacity_card" /> увеличивает число слотов фильтра.
*   <ItemLink id="speed_card" /> увеличивает количество ресурсов, переносимых за операцию.
*   <ItemLink id="fuzzy_card" /> позволяет шине фильтровать по степени износа и/или игнорировать NBT предметов.
*   <ItemLink id="inverter_card" /> переключает фильтр с белого списка на чёрный.
*   <ItemLink id="redstone_card" /> добавляет управление редстоуном: работа при высоком сигнале, низком сигнале или однократно на каждый импульс.
