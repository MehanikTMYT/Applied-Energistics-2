# Верстак для ячеек

<BlockImage id="cell_workbench" scale="8" />

Верстак для ячеек позволяет настраивать [ячейки хранения](storage_cells.md) и <ItemLink id="view_cell" />.

Можно добавлять [карты улучшений](upgrade_cards.md) и задавать «разметку», ограничивающую содержимое ячейки.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если самих предметов нет в наличии.

Щелчок правой кнопкой с ёмкостью для жидкости (например, ведром или резервуаром) задаёт фильтр по жидкости, а не по предмету ведра или резервуара.

## Настройки

В левом верхнем углу верстака для ячеек есть несколько кнопок:

*   Можно разметить ячейку по её текущему содержимому
*   Можно очистить разметку ячейки
*   Верстак можно настроить на сохранение разметки после извлечения ячейки, чтобы копировать настройки между ячейками.
