# МЭ излучатель уровня

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/level_emitter.snbt" />
</GameScene>

Излучатель уровня выдаёт сигнал редстоуна в зависимости от количества предмета в
[сетевом хранилище](../ae2-mechanics/import-export-storage.md).

Есть также вариант, выдающий сигнал редстоуна в зависимости от запаса [энергии](../ae2-mechanics/energy.md)
в сети.

Предметы и жидкости можно перетаскивать в слот из JEI/REI, даже если их нет в наличии.

Щёлкните правой кнопкой мыши с ёмкостью для жидкости (например, ведром или резервуаром), чтобы задать фильтр по жидкости, а не по самому ведру или резервуару.

Это [компоненты кабеля](../ae2-mechanics/cable-subparts.md).

В отличие от других [устройств](../ae2-mechanics/devices.md), излучатели уровня *не требуют* [канала](../ae2-mechanics/channels.md).

## Настройки

*   Излучатель уровня можно настроить на режим «больше или равно» либо «меньше»
*   При установке <ItemLink id="crafting_card" /> можно выбрать «выдавать сигнал редстоуна во время изготовления предмета» или
    «выдавать сигнал редстоуна для изготовления предмета»

## Улучшения

Излучатель уровня поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="fuzzy_card" /> позволяет излучателю фильтровать по степени износа и/или игнорировать NBT предметов
*   <ItemLink id="crafting_card" /> включает функции изготовления

## Функции изготовления

Если установлена <ItemLink id="crafting_card" />, излучатель переходит в режим изготовления.

При этом становятся доступны два варианта:

Первый вариант, «выдавать сигнал редстоуна во время изготовления предмета», заставляет излучатель выдавать сигнал, пока система [автокрафта](../ae2-mechanics/autocrafting.md)
изготавливает определённый предмет через <ItemLink id="pattern_provider" />. Это позволяет включать отдельные
энергозатратные автоматические установки только тогда, когда они действительно используются.

Второй вариант, «выдавать сигнал редстоуна для изготовления предмета», особенно полезен для бесконечных ферм и
автоматических установок, которые выдают результат лишь с некоторой вероятностью, а не гарантированно.
Эта настройка создаёт виртуальный [шаблон](patterns.md) для системы [автокрафта](../ae2-mechanics/autocrafting.md), производящий предмет,
указанный в слоте фильтра излучателя.
(Для корректной работы настоящий шаблон того же предмета **не должен присутствовать** в <ItemLink id="pattern_provider" />)

Этот «шаблон» не задаёт ингредиентов и вообще их не учитывает.
Он лишь сообщает: «Если этот излучатель уровня выдаст сигнал редстоуна, МЭ-система получит данный предмет в какой-то момент
ближайшего или отдалённого будущего». Обычно это используют для включения и отключения бесконечных ферм, которым не нужны входные ингредиенты,
или для запуска [системы обработки рекурсивных рецептов](../example-setups/recursive-crafting-setup.md) (которые обычный автокрафт не понимает),
например «1 булыжник = 2 булыжника», если есть механизм, удваивающий булыжник.
