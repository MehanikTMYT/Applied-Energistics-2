# Беспроводные терминалы

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

Беспроводные терминалы — переносные версии обычных проводных [терминалов](terminals.md). Их интерфейсы полностью совпадают с интерфейсами
проводных аналогов, но вместо слотов для <ItemLink id="view_cell" /> предусмотрены слоты для [карт улучшения](upgrade_cards.md)

Для привязки к сети вставьте терминал в правый верхний слот <ItemLink id="wireless_access_point" />,
подключённой к этой сети. (Слот с изображением беспроводного терминала и стрелкой под ним.)

Для работы они должны находиться в зоне действия <ItemLink id="wireless_access_point" />.

Их можно заряжать в <ItemLink id="charger" />.

# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />

Обычный терминал теперь можно носить с собой! Просматривайте содержимое [сетевого хранилища](../ae2-mechanics/import-export-storage.md), получайте к нему доступ
и запрашивайте предметы у системы [автокрафта](../ae2-mechanics/autocrafting.md) из любой точки в зоне действия
<ItemLink id="wireless_access_point" />.

# Беспроводной терминал изготовления

<ItemImage id="wireless_crafting_terminal" scale="4" />

Беспроводной терминал изготовления похож на обычный беспроводной терминал и имеет те же настройки и разделы, но дополнен сеткой изготовления, которая автоматически
пополняется из [сетевого хранилища](../ae2-mechanics/import-export-storage.md). Будьте осторожны, забирая результат с зажатым Shift!

## Интерфейс

Беспроводной терминал изготовления поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="energy_card" /> для увеличения ёмкости аккумулятора
