# Ячейка просмотра

<ItemImage id="view_cell" scale="2" />

Ячейки просмотра фильтруют отображаемое содержимое [терминалов](terminals.md). Их фильтр настраивается в <ItemLink id="cell_workbench" />.

Например, нужно, чтобы терминал показывал только определённые каменные строительные материалы. Настройте фильтр ячейки просмотра на эти
материалы и поместите её в терминал — отображаться будут только они.

Ячейки просмотра дополняют друг друга: если установить ячейку для дубовых досок и ячейку для булыжника,
будут отображаться и доски, и булыжник.
