# Кабельный якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные штыри, устанавливаемые на кабель. Они позволяют запрещать соединение кабелей, делать из кабелей лестницы или создавать видимость
крепления кабеля к окружающим стенам. Также используются для создания <ItemLink id="facade" />.

Кабельный якорь запрещает соединение с той стороны, где он установлен.

По ним можно подниматься как по лестнице.
