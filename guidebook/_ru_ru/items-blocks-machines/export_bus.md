# МЭ шина экспорта

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/export_bus.snbt" />
</GameScene>

Шина экспорта извлекает предметы и жидкости (а с дополнениями — и другие ресурсы) из [сетевого хранилища](../ae2-mechanics/import-export-storage.md)
и помещает их в инвентарь, к которому примыкает.

Чтобы уменьшить нагрузку, шина экспорта, которая некоторое время ничего не перемещала, переходит в своего рода
«спящий режим» с редкими операциями. После успешного экспорта она просыпается и разгоняется до полной скорости (4 операции в секунду).

Это [компоненты кабеля](../ae2-mechanics/cable-subparts.md).

## Фильтрация

По умолчанию шина ничего не экспортирует. Предметы в слотах фильтра задают список разрешённых:
экспортироваться будут только указанные предметы.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если самих предметов нет в наличии.

Щелчок правой кнопкой с ёмкостью для жидкости (например, ведром или резервуаром) задаёт фильтр по жидкости, а не по предмету ведра или резервуара.

## Улучшения

Шина экспорта поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="capacity_card" /> увеличивает число слотов фильтра.
*   <ItemLink id="speed_card" /> увеличивает количество ресурсов, перемещаемых за операцию.
*   <ItemLink id="fuzzy_card" /> позволяет фильтровать по степени повреждения и/или игнорировать NBT предметов.
*   <ItemLink id="crafting_card" /> позволяет шине отправлять запросы в систему [автокрафта](../ae2-mechanics/autocrafting.md)
    для получения нужных предметов. Можно настроить извлечение из хранилища, если предметы есть в наличии, либо обязательный запрос
    на изготовление нового предмета.
*   <ItemLink id="redstone_card" /> добавляет управление редстоуном: работа при высоком сигнале, низком сигнале или одна операция за импульс.
