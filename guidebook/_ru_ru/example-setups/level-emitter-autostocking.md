# Поддержание запасов с помощью излучателя уровня

Может возникнуть вопрос: «Как поддерживать определённый запас предмета, изготавливая новые по мере необходимости?»

Один из способов — использовать <ItemLink id="export_bus" />, <ItemLink id="level_emitter" /> и <ItemLink id="crafting_card" /> для автоматического запроса новых предметов
через [автокрафт](../ae2-mechanics/autocrafting.md) сети. Эта схема предназначена для поддержания большого запаса одного предмета.

Разумеется, можно заставить сеть изготавливать предметы непрерывно, убрав излучатель уровня и редстоуновую карту.

## Настройки

* <ItemLink id="export_bus" /> (1) настроена на фильтрацию нужного предмета. В ней установлены <ItemLink id="redstone_card" /> и <ItemLink id="crafting_card" />.
  «Режим редстоуна» установлен на «Активируется сигналом», «Поведение при изготовлении» — на «Не использовать имеющиеся в наличии предметы, только изготавливать предметы при экспорте».
* У <ItemLink id="level_emitter" /> (2) заданы нужный предмет и количество, выбран режим «Излучать, когда уровни находятся ниже предела».
* <ItemLink id="interface" /> (3) имеет настройки по умолчанию.

## Принцип работы

1. Если количество нужного предмета в [сетевом хранилище](../ae2-mechanics/import-export-storage.md) ниже значения, указанного в
   <ItemLink id="level_emitter" />, он излучает сигнал редстоуна.
2. Получив сигнал редстоуна (а также благодаря <ItemLink id="crafting_card" /> и запрету на использование имеющихся предметов),
   <ItemLink id="export_bus" /> запрашивает через [автокрафт](../ae2-mechanics/autocrafting.md) сети изготовление
   дополнительных экземпляров нужного предмета, а затем экспортирует их.
3. Получив предмет (и не имея настройки на хранение чего-либо во внутреннем инвентаре), <ItemLink id="interface" /> отправляет его в сетевое хранилище.
